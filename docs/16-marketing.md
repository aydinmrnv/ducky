# Marketing

The biggest driver of revenue is downloads. Start marketing before the app exists.

## Positioning lines
- "Learn to build with AI, and actually understand what it built."
- "Ducky writes code. You catch its mistakes."
- "Every answer is run and checked. No AI slop."
- "You never type code on your phone."
- "$4.99/month."

## Faceless short-form video (main channel)

The owner doesn't want to show his face or talk. The puzzle format doesn't need either, and the lessons double as content.

### Formats
1. **Spot the bug:** code on screen, "Can you spot the bug? 90% can't," countdown timer, reveal. Trending audio. 10 to 20 seconds.
2. **What does this print?** Same structure, classic gotchas (`"2" + 2`, `0.1 + 0.2`).
3. **AI confidently wrong:** "I asked AI for X. It said 'trust me.' Find the problem." Reveal the bug.
4. **Vibe coding disasters:** "This app leaked its API key in 3 lines. Where?" (security bugs get strong reactions).
5. **Build in public:** screen recordings of building the app, captioned. "Day 12 building a Duolingo for coding as a student."
6. **Duck reactions:** the mascot reacting to bad code (once the art exists).

### Rules
- Hook in the first 1 to 2 seconds as on-screen text.
- Code readable on a phone: large mono font, max ~12 lines.
- Answer in a comment or at the end, which drives comments and replays.
- Post daily for 30 days before judging. Track views and saves per format, double down on winners.
- Always the same visual style so people recognize it.

### Workflow (~2 hours/week)
- Pull 7 items from the verified pool (they're already correct).
- Render them with a simple template (a small script or a video editor template).
- Batch-schedule for the week.

## Reddit
- Don't automate. Post genuine build-in-public updates and useful puzzles in relevant communities, following each subreddit's rules.
- Answer questions from people stuck on AI-built apps. Mention Ducky only when it actually helps.

## Launch plan (launch week)
- Founding lifetime offer: $49.99, first 500.
- Product Hunt launch.
- Waitlist email with the founding offer.
- Reddit and X build-in-public posts with the story.
- Daily puzzle videos pointing to the App Store.

## App Store Optimization
- Name: "Ducky: Learn to Code with AI"
- Subtitle: keyword-rich, under 30 characters.
- Keywords: learn coding, AI coding, vibe coding, programming, JavaScript, code, debugging, prompt.
- Screenshots: real puzzle screens with short benefit captions. First screenshot = the core promise.
- Preview video: a real Spot the Bug round in 15 seconds.
- Ask for ratings at happy moments using `SKStoreReviewController` / `requestReview` (e.g. after a 7-day streak). Never reward ratings.
